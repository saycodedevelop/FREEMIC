### การตรวจสอบ

ขั้นตอนเผยแพร่ตรวจ Android build/lint, หน้าเล่นเพลง, microphone foreground service, การค้นหาเครื่องและไมค์สองเครื่อง รวมถึงการทดสอบ C++ ด้วย sanitizers และการจำลอง jitter/clock drift
ยังต้องตรวจคุณภาพ Bluetooth การจัดการแบตเตอรี่ และเสียงพร้อมกันบนอุปกรณ์จริง
